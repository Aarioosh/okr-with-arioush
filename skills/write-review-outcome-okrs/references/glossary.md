# واژه‌نامهٔ نگارشی

این جدول قرارداد نگارشی اسکیل است. در تیترهای تخصصی، انگلیسی را در اولین کاربرد داخل پرانتز نگه دار؛ در متن از تکرار بی‌دلیل انگلیسی پرهیز کن. معنای واژه را در بافت تشخیص بده؛ مثلاً فعل target همیشه اسم «سطح هدف» نیست.

| English | فارسی |
|---|---|
| OKR | اهداف و نتایج کلیدی |
| Outcome-driven OKRs | OKRهای پیامدمحور |
| Objective | اهداف کلان |
| Goal | هدف |
| Key Result | نتیجهٔ کلیدی |
| Initiative | ابتکار |
| Task | وظیفه |
| KPI / Key Performance Indicator | شاخص کلیدی عملکرد |
| Target | سطح هدف |
| Numerical target | سطح عددی هدف |
| Metric | سنجه |
| Measurement | اندازه‌گیری |
| Outcome | پیامد |
| Customer outcome | پیامد مشتری |
| Customer-centric | مشتری‌مدارانه |
| Customer focus | تمرکز بر مشتری |
| Behavior change | تغییر رفتار |
| Goal-setting framework | چارچوب هدف‌گذاری |
| Work product | محصول کار |
| Completion of a task | انجام کار |
| Launch of a product | عرضهٔ محصول |
| Who | چه کسی |
| What | چه کاری |
| By how much | چقدر |

برای جلوگیری از خلط، Output را «خروجی» و Impact را «اثر» بنویس؛ این دو معادل تکمیلی‌اند، نه جایگزین پیامد. Objective حتی در اشاره به یک مورد با برچسب ثابت «اهداف کلان» نوشته شود؛ صورت روان «یک مورد از اهداف کلان» مجاز است.
